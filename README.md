## What I'm building

- **[TasteID](https://taste-id.me)** — **Plaid for consumer data, starting with music.** GDPR data exports connect full listening histories to permissioned behavioral taste profiles. Our audio pipeline analyzes available track previews for genre, mood, instruments, vocals, and tempo.

  We're building audience intelligence for labels and distributors, priced per query, to answer **“Who is this song for?”** before release. Music is the first use case for a broader consumer data platform.

  I built the stack from audio enrichment and data capture to production infrastructure. My co-founder, [Gregg Sgarlata](https://www.linkedin.com/in/sgar), leads growth and partnerships and brings firsthand experience as an independent artist with 10M+ streams.

  **Raising $250K** to scale the data graph and launch the query product. [Let's talk](mailto:hello@taste-id.me).

- **Gig Collective** — CRM + AI assistant for working musicians. Inbox → pipeline (`lead → pitched → booked → played`), drafting in your own voice, scheduled sends, People × Rooms × Deals, and shared venue intel across a roster. Built around my own booking pipeline.

- **[nickrainsmusic.com](https://nickrainsmusic.com)** — fan site + live show platform. Real-time song queue with Stripe-powered boosts, goal-song campaigns, fan capture (The Club), QR ticketing with a door scanner, and an EPK. Built on Cloudflare Pages.

Previously, I built a dynamic soul-bound NFT project that generated **$88K in day-one revenue**.
