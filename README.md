## What I'm building

- **[nickrainsmusic.com](https://nickrainsmusic.com)** — fan site + live show platform. Real-time song queue with Stripe-powered boosts, goal-song campaigns, fan capture (The Club), QR ticketing with door scanner, and an EPK. One Cloudflare Pages project, no third-party services.
- **Gig Collective** — CRM + AI assistant for working musicians. Inbox → pipeline (`lead → pitched → booked → played`), context-aware drafting in your own voice, scheduled sends, People × Rooms × Deals, shared venue intel across a roster. Built and dogfooded against my own booking pipeline.
